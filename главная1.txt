## 1. Цель

На главной странице `loraleya.ru` блок сценариев («Какой стол вы накрываете сегодня?») должен показывать **6 ячеек** вместо текущих **4**:

- **5 карточек сценариев** (Романтический ужин, Семейный обед, Праздничный стол, **День рождения** — появится после E2, Каждый день)
- **1 декоративная CTA-ячейка** «Свой стол, свой повод» со ссылкой на `/individualnyy-zakaz/`

Раскладка — **3 колонки × 2 ряда** на десктопе. Адаптив сохраняется: на планшете — 2 колонки × 3 ряда, на мобильном — 1 колонка × 6 рядов.

## 3. Правка 1 — `front-page.php`

**Найти** (примерно строка 36):

$scenarios = new WP_Query([

### 3.3. Добавить статичную CTA-ячейку после цикла

**Найти конец цикла сценариев** (примерно строки 80-83, после `endforeach; endif; ?>`):
```php

            <!-- 6-я ячейка: CTA на индивидуальный заказ -->

                <div class="scenario-card--cta__content">

                </div>
            </a>

    </div>

```

**Заметки:**
- Ссылка через `home_url('/individualnyy-zakaz/')` — slug страницы индивидуального заказа на момент написания этого ТЗ. Если slug страницы у вас другой — измени только URL внутри `home_url(...)`, всё остальное оставь как есть. Перед правкой проверь slug через wp-admin → Страницы.
- Все классы CTA-ячейки используют BEM-модификатор `scenario-card--cta` и собственные дочерние элементы `__bg`, `__content`, `__mark`, `__name`, `__hint`, `__arrow` — чтобы не конфликтовать со стилями обычных карточек.
- Символ `✦` — это U+2726 (BLACK FOUR POINTED STAR). Если он не отображается в кодировке файла — используй HTML-entity `&#10022;`.

## 4. Правка 2 — `style.css`

### 4.1. Изменить grid с 4 колонок на 3 + убрать шахматку

**Найти** (примерно строки 543-548):
```css
.scenarios-grid {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    gap: 1rem;
    margin-top: 2.5rem;
}
```

**Заменить на:**
```css
.scenarios-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 1rem;
    margin-top: 2.5rem;
}
```

**Найти** (примерно строки 562-564):
```css
.scenario-card:nth-child(even) {
    margin-top: 2rem;
}
```

**Удалить целиком** (3 строки). Шахматный эффект на сетке 3×2 даёт ассиметрию (опустятся 2-я, 4-я, 6-я — диагональ), что выглядит хаотично. Сетка остаётся ровной.

### 4.2. Удалить устаревший nth-child для плейсхолдер-градиентов

В коде есть фрагмент (примерно строки 579-589):
```css

.scenario-card:nth-child(3) .scenario-bg--placeholder { background: linear-gradient(160deg, #2a2010, #1a150a, #0f0c06); }
.scenario-card:nth-child(4) .scenario-bg--placeholder { background: linear-gradient(160deg, #181e24, #0e1318, #080c0f); }
```

Это градиенты для 2-й, 3-й, 4-й placeholder-карточек. После добавления ДР как 4-й позиции, нужно:
1. Сдвинуть существующие правила: позиция 4 → 5 (Каждый день остаётся последним).
2. Добавить градиент для ДР на позиции 4.

**Заменить весь блок (строки 579-589) на:**
```css
/* 2 — Семейный обед: зелёный */
.scenario-card:nth-child(2) .scenario-bg--placeholder {
    background: linear-gradient(160deg, #1e2418, #141a0e, #0c0f08);
}
/* 3 — Праздничный стол: бронзово-золотой */
.scenario-card:nth-child(3) .scenario-bg--placeholder {
    background: linear-gradient(160deg, #2a2010, #1a150a, #0f0c06);
}
/* 4 — День рождения: глубокий бордово-золотой */
.scenario-card:nth-child(4) .scenario-bg--placeholder {

    background: linear-gradient(160deg, #181e24, #0e1318, #080c0f);

```

Первый цвет (Романтический ужин, nth-child(1)) задаётся базовым правилом `.scenario-bg--placeholder` строкой 575-577, не трогаем.

## 5. Критерии готовности

Проверь в браузере **на staging или локально** (не на проде):

### 5.1. Desktop (≥1025px)
- [ ] Видны 6 ячеек: 5 сценариев в порядке Романтический → Семейный обед → Праздничный стол → День рождения → Каждый день, 6-я — CTA
- [ ] Сетка 3 колонки × 2 ряда, все ячейки одного размера (aspect-ratio 3:4)
- [ ] Нет шахматного смещения — все 6 ячеек на одной линии в каждой строке
- [ ] CTA-ячейка визуально отличается: нет фото, есть золотистый glow, есть `✦`, курсивное название, видна стрелка
- [ ] Hover на CTA: лёгкая золотая обводка усиливается, стрелка слегка двигается вправо, бэкграунд стрелки слегка золотится
- [ ] Hover на обычной карточке: работает как раньше (translateY, scale фона, появление стрелки в правом верхнем углу)

### 5.2. Tablet (641-1024px)
- [ ] Сетка 2 колонки × 3 ряда — 6 ячеек ровно, без перекосов
- [ ] CTA-ячейка остаётся 6-й (правый нижний угол)
- [ ] Никаких горизонтальных скроллов

### 5.3. Mobile (≤640px)
- [ ] Сетка 1 колонка × 6 рядов
- [ ] aspect-ratio карточек переключился на 4:3 (как у обычных)
- [ ] CTA-ячейка: текст выровнен по центру (благодаря медиа-правилу)

### 5.4. Функциональное
- [ ] Клик по CTA-ячейке ведёт на `/individualnyy-zakaz/`
- [ ] Клики по 5 сценариям ведут на соответствующие `/scenarios/{slug}/`
- [ ] Если применяется только E1 без E2 (то есть в БД ещё 4 сценария) — будет видно 4 + 1 CTA = 5 ячеек, грид 3×2 с одной пустой ячейкой → **это временное состояние, требующее немедленного применения E2**
