# ТЗ-9: Фикс URL — сценарии (with_front) + битые ссылки

**Версия:** 1.0
**Дата:** 06.06.2026
**Тип:** правка `functions.php` + `taxonomy-pa_fabric_color.php` (Claude Code) + правки текста 3 статей (Борис, в админке)
**Исполнитель:** Claude Code (Фазы 1–2) + Борис (Фаза 3)
**Автор ТЗ:** Sprint-Клд

> Закрывает обратную связь по ссылкам. Корень бага сценариев найден по аудиту URL: CPT `scenario` зарегистрирован без `with_front => false`, поэтому после смены пермалинков на `/blog/%postname%/` сценарии уехали с `/scenarios/...` на `/blog/scenarios/...`, и все ссылки на них (в статье и на палитре) перестали работать. Чиним системно.

---

## Карта реальных URL (из аудита) — целевые адреса
- Сценарии сейчас: `/blog/scenarios/{slug}/` → ДОЛЖНО стать `/scenarios/{slug}/` (Фаза 1).
- Цвета: `/color/{slug}/` (ок, не трогаем).
- Готовый набор: `/product/gotovyj-nabor/` (карточка товара) — цель для «готовый набор/комплекты».
- Палитра: отдельной страницы нет; рабочий якорь — `/#palette` (временно; отдельную страницу палитры заведём позже).

## ФАЗА 1 — `functions.php`: вернуть сценарии на `/scenarios/`

В регистрации CPT `scenario` добавить `'with_front' => false` в массив `rewrite`.

**НАЙТИ** (строка ~123):
```php
        'rewrite'      => ['slug' => 'scenarios'],
```
**ЗАМЕНИТЬ НА:**
```php
        'rewrite'      => ['slug' => 'scenarios', 'with_front' => false],
```

После применения **обязательно пересохранить ссылки** (Фаза 4) — без этого rewrite не перестроится.

> Это вернёт сценарии с `/blog/scenarios/{slug}/` на `/scenarios/{slug}/`. Все ссылки на сценарии в коде (на цветовой странице, строки 351/743 — `home_url('/scenarios/'...)`) и в статье «Праздник» (`/scenarios/...`) сразу станут рабочими — править их не нужно.

---

## ФАЗА 2 — `taxonomy-pa_fabric_color.php`: битая кнопка «Палитра»

Кнопка ведёт на несуществующий `/palette/`.

**НАЙТИ** (строка ~341):
```php
                <a href="<?php echo home_url('/palette/'); ?>">Палитра</a> →
```
**ЗАМЕНИТЬ НА:**
```php
                <a href="<?php echo home_url('/#palette'); ?>">Палитра</a> →
```

> Временное решение на рабочий якорь. Когда сделаем отдельную страницу палитры — переключим сюда её адрес.

## ФАЗА 3 — правки ссылок в статьях (Борис, в админке)

Это текст статей (контент в БД), правится в редакторе: Записи → открыть статью → блок «Произвольный HTML» → «Редактировать как HTML» → заменить адрес в нужной ссылке → Обновить.

### Статья «Хлопок или полиэстер?» (`kak-vybrat-skatert-hlopok-ili-poliester`)
1. **«17 оттенках»** — НАЙТИ `href="/color/bezhevyj/"` → ЗАМЕНИТЬ на `href="/#palette"`.
2. **«готовые комплекты»** — НАЙТИ `href="/product-category/gotovye-nabory/"` → ЗАМЕНИТЬ на `href="/product/gotovyj-nabor/"`.

### Статья «Как накрыть стол на праздник» (`kak-nakryt-stol-na-prazdnik`)
3. **«готовые наборы»** — НАЙТИ `href="/product-category/gotovye-nabory/"` → ЗАМЕНИТЬ на `href="/product/gotovyj-nabor/"`.
4. Ссылки на сценарии (`/scenarios/semejnyj-obed/`, `/scenarios/den-rozhdenija/`, `/scenarios/prazdnichnyj-stol/`) — **НЕ ТРОГАТЬ.** После Фазы 1 они заработают.
5. «Как красиво сложить салфетку» (`/blog/kak-slozhit-salfetki/`) — **оставляем.** Статью напишешь отдельно, тогда ссылка оживёт.

> Если правишь статьи как нормализованные файлы и перезаливаешь — те же замены сделаны в `.md`-исходниках по тем же адресам.

## ФАЗА 4 — пересохранить постоянные ссылки (Борис)
