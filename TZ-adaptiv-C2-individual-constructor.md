# ТЗ Code-Клоду — Адаптив, компонента C2: КОНСТРУКТОР ИНДИВИДУАЛЬНОГО ЗАКАЗА

*Бридж от Спринт-Клода по `tz-adaptiv-mobile-tablet.md` (4.C, вторая половина). C1 (сценарий) принят. Это C2 — конструктор `/individualnyy-zakaz/`, классы `.co-*` (своя вёрстка, не `.ir`).*

**Файл:** `style.css`
**Гейты:** rem; новый `!important` не плодить; ноль CLS; тач ≥44×44; НЕ трогать логику/разметку/цены/тексты.

**Что выяснено разведкой (чтобы не делать лишнего):**
- Строка `.co-item-row` — flex «имя слева · (тумблер + количество) справа», `justify-content:space-between`. В лесенку НЕ разваливается — двухстрочная переделка как у `.ir` НЕ нужна.
- Конструктор уже адаптирован: на ≤640 левые отступы (`margin-left`) у `.co-*` сняты, фичи в колонку. Это трогать не надо.
- Персоны `.co-per` = 2.8rem ≈ 45px — тач ок. Свотчи `.co-sw` = 38px — приемлемо.
- **Проблема одна:** `.co-qty-btn` = **28px** (`.co-qty-val` min-width 28px) — мелко для пальца. Это и чиним.
- Sticky-бара на этой странице НЕТ (там статичные `.co-summary` + `.co-submit-area`) — конфликта B нет, FAB на штатном месте.

## 0. Git-чекпойнт

```bash
git add -A && git commit -m "checkpoint before adaptive-C2 individual-order constructor" --allow-empty

```

## 1. Тач-размер кнопок количества — добавить В КОНЕЦ `style.css`
```css
/* Адаптив C2: кнопки количества в индивидуальном заказе под палец (≥44px на тач) */
@media (pointer: coarse) {
    .co-qty-btn { width: 2.75rem; height: 2.75rem; font-size: 1.1rem; }
    .co-qty-val { min-width: 2rem; }
    .co-item-right { gap: 0.6rem; } /* чуть теснее, чтобы имя слева не зажималось */
}
```
- `pointer: coarse` — как в C1 (на десктопе мышкой размер не раздуваем; на реальном телефоне сработает).
- `.co-item-right { gap }` уменьшен, чтобы при крупных кнопках имя позиции не зажималось на 360.

## 2. Что НЕ делаем
- Не переделываем `.co-item-row` (она уже корректная flex-строка).
- Не трогаем существующий мобильный блок `.co-*` (≤640, margin-left:0), персоны, свотчи, логику/разметку.

## 3. Приёмка (на реальном тач-устройстве / эмуляции тача; ширины 768 / 414 / 360)
1. На `/individualnyy-zakaz/` кнопки количества **крупные** (палец попадает), число между ними не прыгает.
2. Строка позиции читается: имя слева, тумблер + количество справа; нет горизонтального скролла; имя при необходимости переносится, не ломая строку.
3. Тумблер включения позиции и кнопки количества работают на тач.
4. Персоны и свотчи выбираются пальцем (как было).
5. (Контроль) FAB на этой странице на штатном месте (sticky-бара нет); если он перекрывает кнопку отправки/согласие внизу — сообщи, это отдельная мелочь (общий FAB, не C2).
