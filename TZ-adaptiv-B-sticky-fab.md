# ТЗ Code-Клоду — Адаптив, компонента B: конфликт `total-sticky` × `cart-fab`

*Бридж от Спринт-Клода по `tz-adaptiv-mobile-tablet.md` (4.B). Компонента A (меню) принята. Эту берём, B — следующая по очереди.*

**Файл:** `style.css` (при выборе JS-варианта — ещё `assets/js/main.js`)
**Гейты:** rem; новый `!important` не плодить; ноль CLS; НЕ трогать логику корзины/бара/FAB/цены/тексты.

**Проблема:** на страницах конструктора (сценарий + `/individualnyy-zakaz/`) внизу есть `.total-sticky` (sticky-бар с кнопкой «В корзину»), а также глобальная плавающая `.ll-cart-fab` (`position:fixed; bottom; right`). На мобиле они налезают друг на друга в правом нижнем углу. В баре кнопка «В корзину» уже есть.

## 0. Git-чекпойнт
```bash
git add -A && git commit -m "checkpoint before adaptive-B sticky vs fab" --allow-empty
git tag pre-adaptive-B
```

## 1. Фикс — добавить В КОНЕЦ `style.css`
```css
/* ===== Адаптив B: на страницах с нижним баром прячем плавающую корзину на мобиле ===== */
@media (max-width: 768px) {
  body:has(.total-sticky) .ll-cart-fab { display: none; }
}
```
- Прячет FAB только там, где в DOM есть `.total-sticky` (конструктор). На остальных страницах FAB работает как раньше. На десктопе (>768) — без изменений.
- `:has()` поддержан всеми актуальными браузерами. Если по какой-то причине решите не полагаться на `:has()` — альтернатива на JS (тогда `:has()`-правило не нужно):
  - в `assets/js/main.js`: `if (document.querySelector('.total-sticky')) document.body.classList.add('has-sticky-bar');`
  - CSS: `@media (max-width:768px){ body.has-sticky-bar .ll-cart-fab{display:none} }`

## 2. Что НЕ делаем
- Не трогаем сам `.total-sticky`, базовые стили `.ll-cart-fab`, разметку, логику корзины/AJAX.
- Не лезем в брейкпоинт-лестницу — только добавляем точечный `@media (max-width:768px)`.

## 3. Приёмка (на 768 / 414 / 360 + контроль десктопа)
1. Страница **сценария** и **`/individualnyy-zakaz/`**, ≤768: плавающая круглая кнопка корзины **скрыта**, бар «В корзину» внизу **не перекрыт**.
2. Любая **другая** страница (главная, цвет, блог), ≤768: плавающая кнопка корзины **на месте** и работает.
3. Десктоп (>768) на страницах конструктора: всё как было (FAB виден).
4. **Проверить путь к корзине на мобиле (важно!):** на странице конструктора после «В корзину» — открывается ли модалка корзины / есть ли куда перейти в корзину без FAB?
   - Если да (модалка корзины открывается по добавлению) → скрытие FAB ок, принимаем.
   - Если нет (после скрытия FAB на мобиле корзину с этой страницы не открыть) → **не скрывать, а приподнять FAB над баром**: тогда вместо правила выше дать FAB на этих страницах `bottom`, очищающий высоту бара (итеративно подобрать на устройстве). Сообщи — дам отдельную правку.
