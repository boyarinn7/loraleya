# ТЗ Code-Клоду — Адаптив, компонента B (ПЕРЕСМОТР): приподнять FAB над баром

*Заменяет предыдущий вариант B (скрытие FAB). Причина: модалку корзины открывает ТОЛЬКО клик по `#llCartFab`; кнопка «В корзину» в баре лишь добавляет товар и обновляет счётчик (`loraleya:cart-updated` → updateBadge), модалку не открывает. Значит скрывать FAB нельзя — корзину с этой страницы будет не открыть на мобиле. Поэтому FAB не прячем, а поднимаем над баром.*

**Файлы:** `assets/js/main.js` (+ при необходимости откат CSS-правила из прошлой версии)
**Гейты:** rem; новый `!important` не плодить; ноль CLS; НЕ трогать логику корзины/бара/добавления.

## 0. Git-чекпойнт

## 1. Если предыдущий вариант уже применён — откатить скрытие
Если в `style.css` была добавлена строка из прошлой версии:
```css

```
— **удалить её.** (Если не добавляли — пропустить шаг.)

## 2. Lift — добавить В КОНЕЦ `assets/js/main.js`
```js
/* ===== Адаптив B: приподнять плавающую корзину над нижним баром (мобайл) ===== */
(function () {
  var fab = document.getElementById('llCartFab');
  var bar = document.querySelector('.total-sticky');
  if (!fab || !bar) return; // только на страницах конструктора, где есть бар

  var mq = window.matchMedia('(max-width: 768px)');

  function liftFab() {
    if (mq.matches) {
      // поднять FAB точно над баром (замер реальной высоты + зазор)
      fab.style.bottom = 'calc(' + bar.offsetHeight + 'px + 1.25rem)';
    } else {
      fab.style.bottom = ''; // на десктопе вернуть значение из CSS
    }
  }

  liftFab();
  window.addEventListener('resize', liftFab);
  document.addEventListener('loraleya:cart-updated', liftFab); // бар мог изменить высоту
})();
```
- Замеряет фактическую высоту бара (`offsetHeight`) и ставит FAB ровно над ним с зазором 1.25rem.
- Работает на ≤768; на десктопе сбрасывает (FAB на штатном месте).
- Пересчитывается при ресайзе/смене ориентации и при обновлении корзины (если бар изменил высоту).
- На страницах без бара (`.total-sticky` нет) код выходит сразу — FAB везде как раньше.

## 3. Что НЕ делаем
- Не прячем FAB. Не трогаем бар, логику добавления, AJAX, модалку, цены.
- Не лезем в брейкпоинт-лестницу.

## 4. Приёмка (на 768 / 414 / 360 + контроль десктопа)
1. Страница **сценария** и **`/individualnyy-zakaz/`**, ≤768: круглая кнопка корзины **видна, но поднята над баром** — не перекрывает «В корзину» и сама не перекрыта баром. Зазор между ними есть.
2. Проверить **узкую ширину 360**, где бар выше (встаёт в колонку): FAB всё равно над баром, не налезает.
3. Клик по круглой кнопке **открывает модалку корзины** (доступ к корзине сохранён — это и была цель).
4. Любая другая страница (главная/цвет/блог), ≤768: FAB на штатном месте.
5. Десктоп (>768) на конструкторе: FAB на штатном месте (`bottom:2rem`), как было. CLS=0.
