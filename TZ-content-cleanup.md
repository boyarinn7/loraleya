# ЧАСТЬ C. Цены на главной → динамика

### C1. `functions.php` — добавить хелпер (в конец файла, до закрывающего `?>` если он есть)
```php
/**
 * Минимальная цена товара в виде «от N ₽». Пусто, если цены нет.
 */
function loraleya_min_price_html($id) {
    $product = wc_get_product($id);
    if (!$product) return '';
    $price = $product->is_type('variable')
        ? $product->get_variation_price('min', true)
        : $product->get_price();
    if ($price === '' || $price === null || (float)$price <= 0) return '';
    return 'от ' . number_format((float)$price, 0, '.', ' ') . ' ₽';
}
```
