# ТЗ — Две ручки размера шрифта в кабинете (минимальная правка)

**Контекст.** Файл `account.css` уже доведён заказчиком вручную (высоты разделов отрегулированы тремя переменными `--ll-orders/address/profile-content-shift` — НЕ ТРОГАТЬ их и ничего другого). Нужно добавить **только две ручки на размер шрифта**, чтобы заказчик сам подгонял:

- **(A)** размер крупного заголовка раздела — «Заказы» / «Адреса» / «Профиль».
- **(B)** размер заголовка приветствия — «Здравствуйте, …».

Больше ничего в файле не менять. Не переписывать существующие блоки, не «оптимизировать», не править высоты.

---

## Что добавить

### 1. Переменные — в существующий блок `:root` вверху файла

Сейчас там:
```css
:root {
  --ll-orders-content-shift:   -5rem;
  --ll-address-content-shift:  -6.5rem;
  --ll-profile-content-shift:  -6.5rem;
}
```
Добавить в этот же `:root` две строки (не создавать второй `:root`):
```css
  /* Размер шрифта заголовка раздела (Заказы/Адреса/Профиль): меньше = мельче, больше = крупнее */
  --ll-section-title-size: 2.8rem;   /* ← КРУТИ ЭТО (заголовок раздела) */
  /* Размер шрифта приветствия («Здравствуйте, …»): меньше = мельче, больше = крупнее */
  --ll-greeting-size: 1rem;          /* ← КРУТИ ЭТО (приветствие) */
```

### 2. Применение размера приветствия (B) — правка одной строки

В существующем блоке:
```css
.ll-account-greeting__title {
  font-family: var(--sans);
  font-weight: 400; font-size: 1rem; color: var(--text); margin: 0; letter-spacing: .02em;
}
```
Заменить `font-size: 1rem;` на `font-size: var(--ll-greeting-size);`. Больше в этом блоке ничего не менять.

### 3. Применение размера заголовка раздела (A) — добавить новый блок

Заголовок раздела («Заказы»/«Адреса»/«Профиль») в `account.css` сейчас НЕ стилизуется — он выводится темой. Агенту нужно:
1. Определить фактический селектор этого заголовка (вероятно `.entry-title` / `h1.entry-title` / `.woocommerce-MyAccount-content > h1` — проверить в теме/DOM на странице `/my-account/orders/`).
2. Добавить в конец `account.css` новый блок, вешающий на него размер:
```css
/* ---- Размер заголовка раздела (управляется --ll-section-title-size) ---- */
.woocommerce-account .entry-title {     /* ← заменить на фактический селектор заголовка раздела */
  font-size: var(--ll-section-title-size);
}
```
3. Если у заголовка в теме стоит свой `font-size` с более высокой специфичностью и переменная не подействует — повысить специфичность селектора (НЕ использовать `!important`, если можно обойтись; если иначе никак — допустимо точечно). Цель: меняя `--ll-section-title-size`, заказчик меняет размер «Заказы/Адреса/Профиль» на всех разделах.

---

## Проверка

1. В `:root` вверху — рядом с тремя `*-content-shift` появились `--ll-section-title-size` и `--ll-greeting-size` с русскими комментариями `← КРУТИ ЭТО`.
2. Меняя `--ll-greeting-size` → меняется размер «Здравствуйте, …» на всех разделах.
3. Меняя `--ll-section-title-size` → меняется размер заголовка «Заказы»/«Адреса»/«Профиль» на всех разделах.
4. Высоты разделов (три `*-content-shift`) и всё остальное в файле — НЕ изменились.
5. Стартовые значения подобраны близко к текущему виду (заголовок ~2.8rem, приветствие 1rem) — после правки визуально почти ничего не прыгает, дальше крутит заказчик.

## Ограничения
- Трогать ТОЛЬКО: блок `:root` (добавить 2 строки), строку `font-size` в `.ll-account-greeting__title`, новый блок для заголовка раздела. Больше ничего.
- Не менять высоты, поля, кнопки, формы — заказчик их уже настроил.
