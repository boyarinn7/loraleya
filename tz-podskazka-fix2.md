# ТЗ — Фикс: подсказка профиля не встала под поле (повторно)

**Контекст.** Предыдущая правка не сработала: подсказка «Так ваше имя будет отображаться…» под полем «Отображаемое имя» (страница `/my-account/edit-account/`) всё ещё рвётся и обтекает поле справа.

**Причина (диагностирована):**
1. Поле сужено `max-width: 440px` → справа от поля пустое место.
2. Подсказка WooCommerce по умолчанию `display:inline` → затекает в это пустое место сбоку, а не под поле.
3. Текущее правило `.description { display:block }` НЕ срабатывает — значит реальный тег подсказки в этой версии WooCommerce **не** `span.description` (вероятно `<em>` или `<span>` без класса, либо иная обёртка).

**Только эта правка. Остальное не трогать** (высоты, ручки размеров, поля, кнопки — заказчик настроил).

---

## Что сделать

### Шаг 1 — определить фактический тег подсказки
Открыть DOM на `/my-account/edit-account/`, найти тег подсказки «Так ваше имя…» под полем «Отображаемое имя». Зафиксировать его реальный селектор (класс/тег). Частые варианты в WooCommerce: `em`, `span.description`, `span` без класса внутри `.form-row`, или `.woocommerce-input-wrapper + *`.

### Шаг 2 — заменить существующий блок подсказок на усиленный
В `account.css` блок (строки ~247–258, начинается с `/* ---- Подсказки под полями ...`) заменить на версию с высокой специфичностью и покрытием запасных тегов:

```css
/* ---- Подсказки под полями (description): мелкая строка ПОД полем, на всю ширину ---- */
.woocommerce-account .woocommerce-EditAccountForm p.form-row .description,
.woocommerce-account .woocommerce-EditAccountForm p.form-row em,
.woocommerce-account .woocommerce-EditAccountForm p.form-row > span:not(.woocommerce-input-wrapper),
.woocommerce-account form .form-row .description,
.woocommerce-account span.description,
.woocommerce-account em.description {
  display: block !important;   /* перебиваем inline от WooCommerce */
  clear: both !important;
  float: none !important;
  width: 100% !important;
  max-width: 100% !important;  /* подсказка НЕ ограничена 440px поля */
  margin: .35rem 0 0 !important;
  font-family: var(--sans);
  font-size: .72rem;
  font-style: normal;          /* убрать курсив <em> */
  line-height: 1.4;
  letter-spacing: .02em;
  color: var(--text-muted);
}
```

> Агенту: точный селектор из Шага 1 ОБЯЗАТЕЛЬНО включить в список (заменив/дополнив запасные). `!important` здесь оправдан — WooCommerce задаёт inline/float с высокой специфичностью, иначе не перебить. Цель: подсказка — отдельная мелкая строка под полем, на всю ширину контентной колонки, не сбоку.

### Шаг 3 — проверить, что поле не «тянет» подсказку вбок
Поле «Отображаемое имя» имеет `max-width: 440px`. Подсказка не должна наследовать это ограничение (в правиле выше — `max-width:100%`). Поле оставить 440px, подсказку пустить шире/на всю ширину под ним.

## Проверка
1. На Профиле подсказка «Так ваше имя будет отображаться в разделе аккаунта и при публикации отзывов» — **одна строка ПОД полем** (или ровный перенос на всю ширину), мелкий приглушённый шрифт, БЕЗ обтекания сбоку и без разрыва на две части, уехавшие в разные стороны.
2. Поле «Отображаемое имя» осталось узким (440px) — менять не надо.
3. Остальные поля/высоты/заголовки/ручки — не изменились.
