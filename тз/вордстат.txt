# Wordstat-сессия: инструкция + список запросов

**Цель:** получить частотности (число показов в месяц) по запросам, чтобы кластеризовать семантику и понять приоритеты страниц.

**Формат работы:** интерактивный. Ты прогоняешь пакеты, я анализирую результаты в чате и корректирую список.

---

## Подготовка (5 минут, один раз)

### 1. Открыть Wordstat
https://wordstat.yandex.ru/ — войти под Яндекс ID Куренковой (`loraleya-tex@yandex.ru`) или своим.

### 2. Установить регион
Левая колонка → «Регион» → **«Россия»** (по умолчанию обычно так и есть).

⚠️ Важно: если стоит «Москва» — частоты будут только по Москве, занижено в 5-10 раз. Для нашей задачи (вся РФ) нужен общероссийский регион.

### 3. Установить устройства
Оставить **«Все»** (десктоп + мобильные + планшеты). Премиум-аудитория ищет с обоих.

### 4. Установить расширение Yandex Wordstat Assistant (опционально, но сэкономит часы)

Расширение для Chrome/Firefox/Yandex Browser. Позволяет:
- Копировать частоты пачками
- Сохранять списки запросов
- Автоматически складывать частотности в столбец

Ссылка: https://semantica.in/tools/yandex-wordstat-assistant

Если ставить не хочешь — будем работать вручную, просто медленнее.

## Понимание частотностей

При вводе запроса Wordstat показывает **3 типа частоты:**

| Тип | Как ввести | Что показывает |
|---|---|---|
| **Базовая (широкая)** | `столовый текстиль` | Все запросы со словами «столовый» и «текстиль» в любой форме и порядке, в т.ч. с дополнительными словами. **Раздута, не отражает реальный спрос** |
| **Фразовая** | `"столовый текстиль"` (в кавычках) | Запрос точно с этими словами, но в любых формах и с любыми дополнительными словами вокруг |
| **Точная** | `"!столовый !текстиль"` (с восклицательными знаками) | Точно эти слова, точно в этой форме. **Самая честная цифра.** |

**Что нам нужно:** для каждого запроса собираем **фразовую** частоту `"..."`. Точная — для финальной проверки top-кластеров.

Не нужно тратить время на базовую — она вводит в заблуждение.

## Формат отчёта

После каждого пакета ты скидываешь мне таблицу или просто текст в формате:

```
запрос 1 — N показов в месяц
запрос 2 — N
...
```

Или скриншот, если так быстрее. Я разбираюсь.

⚠️ Если у запроса частота **< 10 показов в месяц** — отметь его «×» или пометь как «низкая». Такие запросы не дают трафика, но интересны как часть кластера для семантической полноты.

⚠️ Если запрос выдаёт **0 показов** или «слишком много вариантов» — пиши «0» или «нет данных».

Это **базовая проверка**, есть ли у бренда уже какая-то узнаваемость. Если по «лоралея» — 0, значит брендовый трафик с нуля строим.

"лоралея текстиль"

"лоралея дорожка"

"loraleya отзывы"

(последний — на случай если бренд знают по локации мастерской)

## Итого: ~90 запросов

В среднем 1 запрос = 15-30 секунд (если без расширения). С расширением — 5-10 секунд.

**Время на полную сессию:** 30-60 минут на твоей стороне.

## Порядок работы

1. **Пакет 1 (брендовые)** — пройди и скинь результаты. Это самый быстрый. По результату обсудим в чате — нужны ли корректировки.
2. **Пакет 2-3** — следующая партия. Тоже жду результатов.
3. **Пакет 4-5** — наша уникальная ниша + сценарии.
4. **Пакет 6** — критичный для решения по блогу.
5. **Пакет 7-8** — последние два.

Между пакетами я смотрю на результаты, могу:
- Попросить тебя добавить запросы, которые всплыли в подсказках Wordstat (правая колонка «С этим запросом ищут»)
- Скорректировать формулировки, если запрос дал 0 — поискать вариант
- Пометить кластер как «слабый» и пропустить остаток

## Бонус-задание (по желанию, для самых въедливых)

При прогоне каждого пакета **обращай внимание на правую колонку Wordstat** — «Запросы, похожие на …». Если видишь там запрос, которого нет в моём списке и он выглядит релевантным — скидывай его частоту в отдельный блок «Найдено по подсказкам». Это будет источником **скрытых запросов**, которые мы не угадали в брейнсторме.

## Что НЕ делаем сейчас

- Не лезем в Wordstat Tools (история запросов, регионы по запросу) — это для финального анализа сезонности, не для базовой частотки
- Не собираем 200-300 синонимов — соберём по результатам первого прогона и подсказкам
- Не используем платные сервисы (Keys.so, Bukvarix, MOAB) — сначала бесплатный Wordstat, дальше посмотрим
