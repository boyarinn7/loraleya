# LoraLeya — Используемые фото в галерее страницы сценария

## Слот 1 — "Общий план стола" (зависит от персон)

| Кол-во персон | Используемый файл | Что на фото (как сейчас) |
|---|---|---|
| **2** | `{префикс}-nabor-4-140.webp` | Сервировка на 4 персоны с короткой дорожкой 140 см |
| **4** | `{префикс}-nabor-4-175.webp` | Сервировка на 4 персоны с длинной дорожкой 175 см |
| **6** | `{префикс}-nabor-6-300.webp` | Сервировка на 6 персон с длинной дорожкой 300 см |

### Что нужно перезалить (если есть возможность)

Главный пробел — **нет настоящих фото для 2 персон**. Сейчас при выборе "2 персоны" клиент видит фото **на 4 персоны**, что вводит в заблуждение.

**Идеальный набор файлов на каждый из 17 цветов:**
- `{префикс}-nabor-2-140.webp` — на 2 персоны с короткой дорожкой 140 см
- `{префикс}-nabor-2-175.webp` *(опционально)* — на 2 персоны с длинной дорожкой 175 см

Когда фото будут — нужно поменять одну строку в коде:
```javascript
var naborKey = persons === 2 ? 'nabor-2-140'  // <-- вот эту
```
с `'nabor-4-140'` на `'nabor-2-140'`.

## Слоты 2–4 (от персон не зависят, только цвет)

| Слот | Используемый файл | Описание |
|---|---|---|
| **2 — Детали · салфетка** | `{префикс}-salfetka-tsvetok.webp` | Сложенная "цветком" салфетка крупно |
| **3 — Детали · куверт** | `{префикс}-kuvert.webp` | Куверт горизонтально |
| **4 — Макро · фактура ткани** | `{префикс}-macro-faktura.webp` | Макро-снимок фактуры ткани |

Эти три слота **уже работают для всех 17 цветов** — все файлы в медиабиблиотеке есть (кроме нескольких пробелов у бирюзы).

## Куда заливать фото

WP Admin → **Медиафайлы** → **Добавить новый**. Имя файла должно быть точно по паттерну `{префикс}-nabor-{персон}-{дорожка}.webp`. Никаких пробелов, кириллицы, заглавных букв.

После загрузки кэш Claude'овской функции обнулится при следующей загрузке страницы — фото подхватятся автоматически.
