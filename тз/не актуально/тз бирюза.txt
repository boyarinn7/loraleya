# ТЗ: Размещение фото цвета «Бирюза» на сайте LoraLeya

## Контекст
Первая партия обработанных фото для цвета «Бирюза» готова и лежит в:
```
/фото/biruza/
```

Все файлы в формате WebP, оптимизированы по весу (до 80 КБ карточки, до 160 КБ hero).
Фото нужно загрузить в WordPress медиабиблиотеку и привязать к соответствующим элементам сайта.

## Технические инструкции

### Загрузка в WordPress
1. Все файлы загрузить через: WP Admin → Медиафайлы → Добавить новый
2. При загрузке WordPress создаст миниатюры автоматически
3. WebP поддерживается WordPress 6.x+ нативно

### Привязка к таксономии fabric_color
Фото привязываются к термину таксономии `fabric_color` со slug `biruza` через кастомные поля (ACF или meta fields).

### Привязка к товарам WooCommerce
Когда товары будут созданы — каждое фото привязывается как «Изображение товара» в карточке WooCommerce:
- Все дорожки Бирюза → `biruza-dorozhka.webp`
- Все скатерти Бирюза → `biruza-dorozhka.webp` (временно)
- Салфетка Бирюза → `biruza-salfetka-tsvetok.webp`
- Куверт Бирюза → `biruza-kuvert.webp`
- Наборы Бирюза → `biruza-nabor-4.webp`

### Alt-теги для SEO
При загрузке прописать alt-теги на русском:
- `biruza-hero-servirovka.webp` → alt="Сервировка стола с бирюзовым текстилем LoraLeya"
- `biruza-dorozhka.webp` → alt="Бирюзовая дорожка на стол жаккардовая LoraLeya"
- `biruza-salfetka-tsvetok.webp` → alt="Бирюзовая салфетка цветком с кольцом LoraLeya"
- `biruza-kuvert.webp` → alt="Бирюзовые куверты для приборов жаккардовые LoraLeya"
- `biruza-nabor-4.webp` → alt="Набор бирюзового текстиля для сервировки на 4 персоны LoraLeya"
- `biruza-macro-faktura.webp` → alt="Фактура бирюзовой жаккардовой ткани LoraLeya крупным планом"
- `biruza-gallery-*.webp` → alt="Бирюзовая сервировка стола LoraLeya"
