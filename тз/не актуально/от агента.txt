1. Блок «Готовые наборы» (taxonomy-fabric_color.php:336–401)
Данных-массива нет — 4 карточки захардкожены в HTML напрямую. Одна переменная перед блоком:


<?php $nabor_photo = loraleya_color_photo($upload_url, $photo_prefix, 'nabor-4'); ?>
Структура каждой карточки:


badge      → строка (Хит / Хит плюс / Семейный / Для большого стола)
name       → строка (Набор на N персон · дорожка NNN)
contents   → строка (Дорожка 40×NNN + N салфетки + N куверта)
set-old    → захардкожена (3 290 ₽ / 3 490 ₽ / 4 490 ₽ / 4 690 ₽)
set-new    → захардкожена (2 790 ₽ / 2 970 ₽ / 3 820 ₽ / 3 990 ₽)
data-item  → (Набор 4п/140 / Набор 4п/175 / Набор 6п/140 / Набор 6п/175)
Фото — одно на все 4 карточки (nabor-4).

2. Блок «Поштучно» (taxonomy-fabric_color.php:403–505)
Массив $products с двумя типами элементов:

С вариантами (variants + default):


cat / name / photo / default (индекс активного варианта)
variants[]: label, size, price, item
Без вариантов (плоская карточка):


cat / name / photo / size / price / item
Скидка считается на лету через round($price / 0.85 / 10) * 10.

Ключевое отличие структур
Наборы	Поштучно
Данные	хардкод HTML	массив PHP
Цены	явно в HTML	вычисляются из price
Варианты	нет (1 карточка = 1 позиция)	есть (табы)
Фото	одно на всех	по типу товара
data-item	вручную	из массива
