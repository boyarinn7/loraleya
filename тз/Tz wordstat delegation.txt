# ТЗ — Wordstat-сессия LoraLeya в отдельном чате Claude

**Назначение:** провести проверку ~55 запросов через отдельный чат Claude (далее — Wordstat-Клод). Это позволяет сохранить контекст основного SEO-чата для последующих этапов.
**Дата:** 19 мая 2026
**Адресат:** Борис + Wordstat-Клод

---

## Как работает делегация

```
Wordstat (источник)
   ↓ скриншоты + CSV
Борис (оператор) 
   ↓ загружает в Wordstat-Клод
Wordstat-Клод (промежуточное звено)
   ↓ структурирует в готовый markdown
Борис → передаёт готовый markdown в основной SEO-чат
   ↓
SEO-Клод (анализирует и интегрирует в семантику)
```

**Ключевой принцип:** Wordstat-Клод НЕ принимает стратегических решений, НЕ комментирует данные, НЕ предлагает гипотез. Его задача — структурировать и нормализовать ввод в один markdown-документ.

## ЧАСТЬ 3. Что Борис скидывает в Wordstat-Клод по каждому запросу

Для каждого запроса из пакета — **3 элемента**:

### 3.1. Скриншот основного экрана Wordstat
- URL запроса в кавычках (фразовое соответствие)
- Видно: основное число запросов в месяц, период (последние 30 дней), регион Россия, галки всех устройств
- Видна таблица «Запросы со словами» (вкладка «Популярные»)

### 3.2. Скриншот вкладки «Похожие»
- Кликнуть на вкладку «Похожие» рядом с «Популярные»
- Скриншот таблицы похожих запросов

### 3.3. CSV-выгрузка (опционально, ускоряет работу)
- Кнопка «Скачать» на странице Wordstat
- CSV содержит топ связанных запросов (вкладка которая активна — «Популярные» или «Похожие»)

**Принцип:** скриншот — обязателен (содержит главное число), CSV — ускоряет распарсивание связанных. Если CSV сложно — только скриншоты, Wordstat-Клод вытащит данные из них.

**Формат загрузки в чат Wordstat-Клода:**
```
Пакет N, запрос M из X: "запрос"
[прикрепить 2 скриншота + опционально CSV]
```

## ЧАСТЬ 4. Формат выходного markdown — то, что Wordstat-Клод возвращает Борису

Эталонный формат, который Wordstat-Клод должен соблюдать:

```markdown
# Wordstat-сессия LoraLeya — результаты

**Дата сбора:** [дата начала и окончания пакетов]
**Регион:** Россия
**Период каждого запроса:** последние 30 дней
**Устройства:** все
**Соответствие:** фразовое (в кавычках)

---

## Пакет 1 — Размеры

### "скатерть 140 см" — 153

**Похожие («Популярные» в Wordstat — включающие):**
- скатерть круглая 140 см — 26
- скатерть овальная 140х220 см кружевная — 10
- скатерть 140 180 см — 8

**Семантически близкие («Похожие» в Wordstat):**
- [запрос] — N
- [запрос] — N

---

### "скатерть 180 см" — N

...
```

**Обязательные правила формата:**
1. Каждый запрос — в кавычках, как в Wordstat (фразовое соответствие)
2. Основное число — после тире
3. Две секции под каждым запросом: «Популярные» (длинный хвост) и «Похожие» (семантика)
4. Если в одной из секций пусто — писать «нет данных», не пропускать секцию
5. Если основное число — 0 или меньше 5 — секции с расширениями всё равно делать
6. Заголовки пакетов — H2 (`##`), запросы — H3 (`###`)
7. После каждого запроса — горизонтальный разделитель `---`
8. В конце документа — сводная статистика (см. ниже)

**В конце документа — сводная таблица:**

```markdown
## Сводная статистика

| Пакет | Запросов | Сумма | Самый высокий |
|---|---|---|---|
| 1. Размеры | 12 | XXXX | "запрос" — N |
| 2. Подарочный | 10 | XXXX | "запрос" — N |
| ... | ... | ... | ... |
| **Итого** | **55** | **XXXX** | — |
```

## ЧАСТЬ 5. Чего НЕ должно быть в выходном документе

❌ Комментариев Wordstat-Клода («это перспективный кластер», «слабая семантика»)
❌ Рекомендаций по стратегии
❌ Перевода в проценты, графиков, визуализаций
❌ Кластеризации (это задача основного SEO-чата)
❌ Сравнений с этапом 1 (Wordstat-Клод не знает этап 1)
❌ Раздела «Выводы» или «Резюме» — только данные
❌ Эмодзи или иконок в таблицах
❌ Сокращений запросов («скатерть 140» вместо «скатерть 140 см»)
❌ Округлений чисел (если Wordstat показал 153 — писать 153, не «~150»)

## ЧАСТЬ 6. Контроль качества и протокол ошибок

### Что должен проверять Wordstat-Клод перед отдачей пакета:

1. Каждый запрос из списка пакета присутствует в выводе (если 12 — то 12 заголовков H3)
2. Основное число есть у каждого (даже если 0)
3. Обе секции (Популярные + Похожие) присутствуют у каждого
4. Формат строго одинаковый
5. Нет пропусков «```» или незакрытых markdown-блоков

### Если данных нет или скриншот нечитаем:

Wordstat-Клод пишет:
```markdown
### "запрос" — [данные не получены: причина]
```

И продолжает с остальными запросами. Не блокирует пакет ради одного запроса.

### Если Wordstat показывает «недостаточно данных»:

```markdown
### "запрос" — менее N (Wordstat: «недостаточно данных»)
```

## ЧАСТЬ 7. Темп работы

**Рекомендация Борису:** один пакет за сессию (60-90 минут):
- 6 запросов × 2-3 минуты в Wordstat = 12-18 минут на сбор скриншотов
- + загрузка в Wordstat-Клод и его обработка = 10-15 минут
- + ревью markdown перед отправкой в основной чат = 5-10 минут

При темпе один пакет в день — все 6 пакетов за 6 дней.

**Возможный ускоренный режим:** 2 пакета за сессию (~2 часа), 3 дня на всё.

---

## ЧАСТЬ 8. Как Борис передаёт результат в основной SEO-чат

После каждого пакета (или всех 6) Борис:

1. Копирует markdown из Wordstat-Клода
2. Сохраняет как файл: `wordstat-session-2-pak-N.md`
3. Прикрепляет в основной SEO-чат с короткой подписью: «Готов Пакет N»

Основной SEO-чат интегрирует данные в семантическую карту и обновляет архитектурные решения если данные того требуют.
