# Инструкция: фото для вариаций товаров (Дорожка, Скатерть, Готовый набор)

> Здравствуйте! Эта задача **не срочная** — можете делать в удобное время. Сайт работает и без неё. Но когда фото будут прикреплены, в модалке корзины и в карточке товара клиенты будут видеть **именно тот цвет** который выбрали, а не общее фото товара.
>
> Задача рутинная: для каждой вариации товара выбрать соответствующее фото из медиабиблиотеки. Все фото уже загружены — нужно только привязать.
>
> **Объём:** 204 вариации (Дорожка 68 + Скатерть 51 + Готовый набор 85). Время — 2-3 часа, можно делить на куски.
>
> **Можно делать постепенно** — например, сначала 5-10 самых популярных цветов, остальные потом.

---

## Подготовка

Перед началом сделайте резервную копию через UpdraftPlus (как в прошлый раз):
WP Admin → **UpdraftPlus** → **Создать резервную копию сейчас** → ОК.

---

## Как привязать фото к одной вариации

Один цикл занимает **~30 секунд**. Покажу на примере **Бежевой Дорожки 140 см**.

1. WP Admin → **Товары** → найти **«Дорожка на стол»** → **Изменить**
2. Перейти на вкладку **«Вариации»**
3. Раскрыть нужную вариацию (нажать на стрелочку или прямо на цвет/размер)
4. Слева увидите **квадрат-плейсхолдер для фото** *(сейчас там пустая «картинка»)*
5. Кликнуть на этот квадрат → откроется **медиабиблиотека**
6. В строке поиска вверху ввести имя файла, например: **`bezheviy-dorozhka`**
7. В результатах появится фото бежевой дорожки → выбрать его
8. Нажать **«Установить изображение вариации»** (синяя кнопка справа внизу)

Всё, фото привязано. Переходим к следующей вариации.

После проработки нескольких вариаций — нажать **«Сохранить изменения»** *(серая кнопка внизу списка вариаций)* и **«Обновить»** товар вверху справа.

### Готовый набор — 85 вариаций (5 размеров × 17 цветов)

Здесь **разные размеры показывают разные фото** — потому что наборы на 2/4/6 персон визуально различаются (количество приборов на столе). Используются 5 разных файлов:

| Размер набора (в WC) | Какой файл |
|---|---|
| **2п/140** | `{префикс}-nabor-4-140` *(временно используем 4-персонное фото; новых на 2 персоны пока нет)* |
| **4п/140** | `{префикс}-nabor-4-140` |
| **4п/175** | `{префикс}-nabor-4-175` |
| **6п/140** | `{префикс}-nabor-6-240` *(используем фото с дорожкой 240, для 140 нет)* |
| **6п/175** | `{префикс}-nabor-6-300` |

**Пример** для бежевого:
- Бежевый, 2п/140 → файл `bezheviy-nabor-4-140`
- Бежевый, 4п/140 → файл `bezheviy-nabor-4-140` *(тот же)*
- Бежевый, 4п/175 → файл `bezheviy-nabor-4-175`
- Бежевый, 6п/140 → файл `bezheviy-nabor-6-240`
- Бежевый, 6п/175 → файл `bezheviy-nabor-6-300`

То есть для одного цвета набора нужно 4 разных файла фото *(2п/140 и 4п/140 показывают одно и то же)*.

## Удобный способ работы

### Стратегия 1 — по цветам (рекомендую)

Брать один цвет и закрывать ему **всё за раз**: дорожка (4), скатерть (3), набор (5) = **12 вариаций на цвет**. После этого готов один цвет полностью.

Делать в таком порядке цветов *(самые популярные первые)*:
1. Платина
2. Бирюза
3. Меланж золото
4. Меланж серый
5. Бежевый
6. Блек золото
7. Зелёный
8. Бронза
9. Тёмно-бирюзовый
10. Графит
11. Меланж серебро
12. Меланж чёрный
13. Серебро
14. Голубой
15. Сиреневый
16. Фиолетовый
17. Белый

Почему так удобнее: каждый цвет в админке открывается в **разных товарах** (дорожка/скатерть/набор — это 3 разных страницы). Делая по цвету, вы трижды открываете одну и ту же страницу для всех вариаций этого цвета и закрываете её совсем.

### Стратегия 2 — по товарам

Берёте **Дорожку** → проходите все 68 вариаций → ставите фото каждой → сохраняете → переходите к **Скатерти** → 51 вариация → к **Готовому набору** → 85.

В этом случае один товар открывается один раз, и в нём проходите все вариации сверху вниз. Удобнее если хотите за один присест закрыть, например, только Дорожки.

**Выбирайте что вам удобнее.**

## Если фото не находится в медиабиблиотеке

Все 17 цветов × 15 типов фото = 255+ файлов уже загружены. Но если по какому-то имени поиск ничего не показывает — возможные причины:

| Проблема | Что проверить |
|---|---|
| Опечатка в имени | Сравните точно с таблицей выше — особенно `seriy` vs `seryj`, `cherniy` vs `chyornyj` |
| В поиске вообще пусто | Откройте **Медиафайлы → Библиотека** и в строке поиска введите имя — увидите есть ли файл |
| Файл не загружен | Если действительно нет — пропустить эту вариацию пока, остальные доделать. Файлы можно догрузить отдельно. |

## Проверка результата

После прикрепления фото к нескольким вариациям — проверьте на сайте:

1. Откройте `loraleya.ru/scenarios/romanticheskij-uzhin/` в **приватном окне** *(чтобы кэш не мешал)*
2. Выберите цвет где привязали фото *(например, Бирюза)*
3. Добавьте дорожку в корзину
4. Откройте корзину
5. **Должно быть видно:** позиция «Дорожка 140» с фото **бирюзовой дорожки** *(не общим фото, не плейсхолдером)*

Если видите правильное фото — значит привязка сработала.
