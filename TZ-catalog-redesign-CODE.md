# ТЗ для Code-агента — Каталог LoraLeya: редизайн + фиксы

**Проект:** loraleya.ru (WordPress + WooCommerce, тема `loraleya` v1.0.0, Reg.ru, WP File Manager, без SSH)
**Контекст:** магазин рендерится ДЕФОЛТНЫМ шаблоном WooCommerce `archive-product.php`. Тема его НЕ переопределяет (папки `theme/woocommerce/` нет). Вся кастомизация — через CSS в `style.css` + фильтры в `functions.php`. Диагностика подтверждена 04.07.2026.

> **Критично:** каталог, товары, цвета УЖЕ проиндексированы Яндексом (~29 стр.) и Google. Все правки — только ОФОРМЛЕНИЕ и вывод. НЕ менять: структуру URL, слаги, контент, логику WooCommerce, шаблоны WC. Меняем CSS + добавляем хуки вывода. Риск для индексации держать минимальным.

## Рабочие правила (обязательны)
- **Диагностика перед действием.** Сначала прочитать реальные файлы (`style.css`, `functions.php`, шаблон карточки), потом писать код. Не писать вслепую.
- **Preview / staging.** Если есть стейджинг — все правки там, потом перенос. Если нет — правки в дочерней теме или отдельном CSS/файле, с возможностью быстро откатить. НЕ править ядро WC и родительские файлы напрямую без бэкапа.
- **Никакого хардкода цен.** Только `$product->get_price_html()` / штатные WC-механизмы.
- **Редполитика:** везде «жаккард» (никогда «полиэстер»); «куверт (конверт для приборов)».
- После правок — **проверить PageSpeed Mobile** (это отдельный гейт проекта, адаптив не должен просесть).
- Агент выполняет узкие задачи блоками, не всё разом. Каждый блок — отдельный коммит.

## БЛОК A — CSS каталога (риск: минимальный, чистая стилизация)

Цель: превратить сетку-плитку страницы магазина в вертикальный **каталог-лукбук**: горизонтальные развороты (фото слева, инфо справа), адаптив в вертикаль на мобильном. Референс-вид согласован с заказчиком (макет прилагается отдельно / см. описание ниже).

### A1. Формат карточки — горизонтальный разворот
- Контейнер `ul.products` — из grid в вертикальный список (одна колонка разворотов).
- Каждый `li.product` — grid из 2 колонок: `minmax(0,300px)` фото | `minmax(0,1fr)` инфо, `gap:2rem`, `align-items:center`.
- Между товарами — тонкая линия-разделитель: `border-bottom:1px solid rgba(197,165,90,.15)`.
- Фото: `aspect-ratio:3/4`, `background-size:cover` (фото у товаров вертикальные 768×1024).
- **Мобильный (`max-width:620px`):** grid в одну колонку (фото сверху, инфо снизу), `.photo{max-width:280px}`.

### A2. Токены и типографика (уже есть в теме, использовать их)
- `--bg:#0e0e0c`, `--gold:#c5a55a`, `--cream:#e8e0d0`.
- Название товара `h2.woocommerce-loop-product__title`: Cormorant Garamond, `clamp(1.7rem,3vw,2.2rem)`, cream.
- Описание/мета: Raleway, 14px, `rgba(232,224,208,.7)`.
- Цена: Cormorant Garamond, 1.5rem, gold.

### A3. Заголовок каталога
- Над списком: эйбрау «Коллекция LoraLeya» (12px, letter-spacing .28em, uppercase, gold) + h1 «Каталог» (Cormorant, cream).
- **Убрать** любую поштучную нумерацию/золотые под-заголовки у карточек (в макете их нет).

### A4. Кнопка «Выбрать»
- Единый текст на всех карточках: **«Выбрать»** (заменяет дефолтное «Выберите параметры» / «Выбрать опцию»).
- Стиль: прозрачная, `border:1px solid rgba(197,165,90,.5)`, uppercase 12px letter-spacing .2em, hover — залив gold + текст `#0e0e0c`.
- Реализовать заменой текста кнопки через фильтр (`woocommerce_product_add_to_cart_text` для variable) + CSS, НЕ правкой шаблона.

## БЛОК B — Фиксы багов каталога (риск: минимальный)

### B1. Прыгающая сетка (ГЛАВНЫЙ баг)
**Причина найдена:** в CSS `.products` задано
```
grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
```
`auto-fill` даёт разное число колонок на разной ширине экрана → на широких мониторах 5 колонок, 5-й товар «съезжает» (4+1). На узких — 4.
**Фикс:** после перехода на формат разворотов (Блок A) `.products` вообще перестаёт быть многоколоночной сеткой — становится вертикальным списком. Баг устраняется самим Блоком A. **Проверить**, что старое правило `auto-fill` удалено/переопределено и не конфликтует.

### B2. Белая выпадашка сортировки
**Причина:** `select.orderby` в `form.woocommerce-ordering` не застилизован → браузерный дефолт (белый фон, чёрный текст) на тёмном фоне.
**Фикс (CSS):** застилизовать `.woocommerce-ordering select.orderby` под тёмную тему: фон `#0e0e0c` или прозрачный, текст cream, рамка `1px solid rgba(197,165,90,.4)`, стрелка — кастомная или оставить нативную но в тёмном. Проверить оба состояния (закрыт/открыт список опций).

### B3. Заголовок «Магазин» лезет под шапку
**Причина:** нет верхнего отступа у контейнера каталога под фиксированную/прозрачную шапку.
**Фикс (CSS):** добавить верхний `padding`/`margin` контейнеру архива магазина, чтобы «Магазин» не перекрывался шапкой. Согласовать величину с высотой шапки. Проверить на десктопе и мобильном.

## БЛОК C — Вывод данных в карточке каталога (риск: низкий, трогает хуки)

### C1. Цена — динамическая
- Диапазон «от — до» выводить штатно `$product->get_price_html()`. НИКАКОГО хардкода чисел. Меняется цена вариации в админке → меняется в каталоге автоматически.

### C2. Краткое описание в карточке
- В разворот вывести **short description товара** (`woocommerce_template_single_excerpt` / `$product->get_short_description()`), чтобы Наталья правила тексты через админку (поле «Краткое описание» товара), НЕ через код.
- Черновые стартовые тексты (заказчик заменит) — см. приложение в конце. Задача агента: обеспечить ВЫВОД поля в карточке каталога через хук `woocommerce_after_shop_loop_item_title` (или аналог), не хардкодить сами тексты.
- Мета-строки (размеры, «17 оттенков», «Жаккард») — по возможности из атрибутов товара; если сложно — вынести в то же короткое описание. Обсудить с заказчиком, если потребуется уточнение.

## БЛОК D — Листание фото на карточке ТОВАРА (риск: выше — функционал, делать отдельным коммитом)

> Это НЕ про каталог, а про страницу отдельного товара (`single-product`). В каталоге карточки статичные (одно фото).

### D1. Поведение
- На карточке товара главное фото **кликабельно**: клик по фото → следующее фото из очереди. Дошли до конца → возврат к первому (зациклено).
- **Без стрелок, без точек, без миниатюр-указателей.** Чистое фото, курсор `pointer`. Намёк на интерактивность — только сменой курсора (опц. лёгкий hover, согласовать).
- Пока у товара одно фото в очереди — клик ничего не меняет (это нормально).

### D2. Источник фото — КОНФИГ-массив (не галерея WC)
- Очередь фото задаётся **явным конфигом** в теме: массив вида `слаг_товара => [ 'файл1.webp', 'файл2.webp', ... ]`.
- Значения — **имена файлов** из медиатеки (напр. `biruza-dorozhka.webp`); код сам достраивает путь к uploads. (Подтверждено заказчиком: оперируем именами файлов, не полными URL.)
- Оформить как отдельный редактируемый конфиг (напр. в `functions.php` или отдельном `config-gallery.php`), чтобы пополнение = дописать строку в массив, БЕЗ правки шаблонов.
- Fallback: если для товара конфига нет / пусто — показывать штатное главное фото товара, клик неактивен.
- На старте у большинства товаров будет по 1 фото; заказчик пополняет очередь по мере досъёмок.

### D3. Не ломать
- Штатную галерею/зум WooCommerce на карточке товара это заменяет/переопределяет — согласовать, чтобы не конфликтовало с lightbox. Приоритет: клик-листание работает, страница не ломается.

## Порядок сдачи
1. Блок B + A (фиксы + вид каталога) — первым, это закрывает видимые баги и даёт результат.
2. Блок C (динамика цен, вывод описания) — следом.
3. Блок E (меню) — быстрый, можно с A/B.
4. Блок D (листание фото) — последним, отдельным коммитом, как самый рискованный.
5. После всего — PageSpeed Mobile, проверка что индексируемая структура не затронута.

## Приложение — черновые описания (СТАРТОВЫЕ, заказчик заменит; НЕ хардкодить)
- **Готовый набор:** Дорожка, тканевые салфетки и куверты в единой жаккардовой ткани и одном оттенке. Готовое решение для стола на 2, 4 или 6 персон — остаётся выбрать цвет.
- **Дорожка на стол:** Центральная линия сервировки. Плотный жаккард с мраморным переливом. Четыре длины — от 140 до 300 см.
- **Скатерть:** Основа праздничного стола. Жаккард с глубоким переливом, три размера под круглый и прямоугольный стол.
- **Салфетка сервировочная:** Тканевая салфетка 40×40 см из того же жаккарда. Сложить веером или свернуть в куверт. Продаётся поштучно.
- **Куверт для приборов:** Тканевый конверт для столовых приборов 9×24 см. Ресторанная деталь сервировки в цвет всего набора.

*Размеры в описаниях — предварительные (из README), заказчику сверить с фактическими перед публикацией.*
