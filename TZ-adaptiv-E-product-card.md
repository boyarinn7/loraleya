# ТЗ Code-Клоду — Адаптив, компонента E: КАРТОЧКА ТОВАРА (полировка)

*Бридж от Спринт-Клода по `tz-adaptiv-mobile-tablet.md` (4.E). D принята. E — лёгкая полировка карточки товара.*

**Файл:** `style.css`
**Гейты:** rem; новый `!important` не плодить (в карточке его и так много — работаем без него); ноль CLS; тач ≥44; НЕ трогать вариации WooCommerce/цены/логику/разметку.

**Что выяснено разведкой (чтобы не делать лишнего):**
- `.single-product div.product` уже 1 колонка на ≤900, галерея `static` — ок.
- `.ll-swatches` уже `flex-wrap` — 17 свотчей (по 2.5rem) переносятся сами. **Править не нужно, только проверить на 360.**
- `.quantity input` 48px — тач ок.
- **Чиним два:** (1) кнопка `.single_add_to_cart_button` на мобиле не на всю ширину; (2) у табов Описание/Детали/Отзывы тач-зона ссылки маленькая (`padding-bottom:.4rem`).

## 0. Git-чекпойнт
```bash
git add -A && git commit -m "checkpoint before adaptive-E product card" --allow-empty
git tag pre-adaptive-E
```

## 1. Кнопка «В КОРЗИНУ» — на всю ширину на мобиле. Добавить В КОНЕЦ `style.css`
```css
/* Адаптив E: на мобиле кнопка добавления в корзину — на всю ширину */
@media (max-width: 768px) {
    .single-product .single_add_to_cart_button { width: 100%; }
}
```

## 2. Табы — крупнее тач-зона на мобиле. Добавить В КОНЕЦ `style.css`
```css
/* Адаптив E: тач-зона табов Описание/Детали/Отзывы на мобиле */
@media (max-width: 768px) {
    .single-product .woocommerce-tabs ul.tabs { gap: 1.25rem; flex-wrap: wrap; }
    .single-product .woocommerce-tabs ul.tabs li a {
        display: inline-block;
        padding: 0.6rem 0;
    }
}
```
- `gap` чуть меньше + `flex-wrap` как страховка (если строка не влезет — перенесётся, а не уедет в горизонтальный скролл).
- `padding` у ссылки увеличивает зону нажатия по вертикали.

## 3. Что НЕ делаем
- `.ll-swatches` (уже переносится), `.quantity input` (48px ок), сетку карточки (1 кол на ≤900 ок), галерею — не трогаем.
- Вариации WooCommerce, цены, логику корзины, разметку — не трогаем.

## 4. Приёмка (на реальном тач-устройстве; ширины 768 / 414 / 360)
1. **Кнопка «В КОРЗИНУ»** на мобиле — на всю ширину, удобно жать.
2. **Свотчи (17 шт)** на 360 — аккуратно переносятся на несколько рядов, не уезжают за край, выбираются пальцем.
3. **Табы** Описание/Детали/Отзывы — не ломаются, нажимаются пальцем (зона выросла), при необходимости переносятся, без горизонтального скролла.
4. Добавление в корзину работает на тач; вариации (если есть) выбираются.
5. Десктоп: всё как было.

## 5. Откат
```bash
git reset --hard pre-adaptive-E
```
